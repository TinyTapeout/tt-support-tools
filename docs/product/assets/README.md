# Datasheet assets

Both files are embedded as data URIs by `build.py`, so the generated HTML is
self-contained. Swap either one by dropping in a replacement and updating the
`assets:` block in `datasheet.yaml`.

| File | Source | Licence |
| ---- | ------ | ------- |
| `archivo.woff2` | [Archivo](https://github.com/Omnibus-Type/Archivo) via Google Fonts, latin subset, variable weight 100–900 | SIL Open Font License 1.1 — see `OFL.txt` |
| `demoboard.jpg` | Tiny Tapeout ETR demoboard quickstart guide, downscaled to 1000px | © 2024 Pat Deegan, psychogenic.com — **not** covered by this repo's Apache-2.0 licence |

The demoboard photo is credited in the datasheet caption. Confirm redistribution
is agreed with the copyright holder before publishing the datasheet externally.
